# Project-B | Signal Tasks

A bold, focused to-do list app built with vanilla HTML, CSS, and JavaScript. Tasks persist in localStorage, and the interface keeps momentum with filters, a streak indicator, and a clean daily board.

## Run locally

Open `index.html` in your browser. No build step is required.

## Live site

[https://paulcaliguid.github.io/Project-B/](https://paulcaliguid.github.io/Project-B/)

## Features

- Add, complete, and remove tasks
- Filters for all, active, and completed tasks
- Local persistence via localStorage
- Completed task count and streak tracker
- Responsive layout
